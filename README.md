# Portfolio webpage

This is a minimal responsive portfolio single-page site. It includes the following sections:

- About Me
- Education
- Experience
- Skills
- Projects
- Contact Me (mock form)

Files:

- `index.html` — main page
- `styles.css` — styling
- `script.js` — small interactions (smooth scroll & mock form)

How to preview

Open `index.html` in your browser. On macOS you can run:

```bash
open index.html
```

Customization

- Replace "Your Name" and content in `index.html` with your details.
- Replace avatar, resume link and project descriptions.
- To enable a real contact form, wire the form submission in `script.js` to an API endpoint.
